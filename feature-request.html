Shape the product

Start with the problem.
We will find the signal.

The best requests explain the decision, investigation, or monitoring task that is difficult today. Requests are tracked in public, so you can see what is already planned.

A useful request includes

What are you trying to accomplish?

  • The task or decision you are trying to complete.
  • Who benefits and how often the need occurs.
  • What you do today and where that workflow breaks down.
  • An example, data source, or screenshot when one is available.

Open the request form

The form walks you through a short structured template. A free account is required to submit.

Create request ↗

Before submitting

Check the existing signal.

1

Search the dashboard

Press Cmd/Ctrl+K. The capability may already exist as a command, map layer, panel, or country view.

2

Review the roadmap

See what is already shipped, next in line, or being explored before opening a duplicate request.

3

Search open issues

If someone reported the same need, add your use case and context to that discussion instead.

4

Keep data public

Do not include credentials, private intelligence, personal data, or confidential organizational details.
