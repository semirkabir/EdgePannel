Opening it the first time

Releases are not always code-signed, so the OS may not recognise the publisher. That warning is expected — here is how to get past it, and how to confirm you have the right file first.

  • macOS: if you see “cannot be opened because it is from an unidentified developer”, right-click the app in Applications and choose Open, then confirm once.
  • Windows: SmartScreen may show “Windows protected your PC” — choose More info → Run anyway.
  • Verify first: each release lists the SHA-256 of every asset in its release notes. Compare it against shasum -a 256 <file> before you open anything.

Links always resolve to the newest published asset for the selected edition. If a build is still uploading you land on the releases page instead.

Why install

What the desktop build adds.

Keys in the OS keychain

Bring your own AI and data provider keys. They are stored by the operating system's keychain, never in browser storage and never on our servers.

Local model support

Point the summarisation chain at Ollama on your own machine. The provider and model pickers are desktop-only.

A local data sidecar

A bundled Rust service fetches feeds directly instead of routing through the web proxy — fewer hops, fewer blocked sources.

In-app updates

The app checks for new releases and offers the matching build for your platform and edition.

Source is AGPL-3.0. You can build any of these yourself: github.com/koala73/worldmonitor.

Not sure yet?

The web app is the whole product, free and without an account. Install later if you want the local extras.
