## 2. Create SEC 13F Filing Service

**New file:** `src/services/market/sec-filings.ts`

Create a dedicated service module to:

### Types
```ts
interface SecFilingEntry {
  id: string;           // Accession number or GUID
  title: string;        // e.g. "13F-HR - Berkshire Hathaway Inc"
  filerName: string;    // Extracted filer name
  cik: string;          // Extracted CIK
  filingType: string;   // e.g. "13F-HR", "13F-NT", "13F-HR/A"
  filedAt: Date;        // Filing date
  url: string;          // Link to full filing on EDGAR
  description?: string; // From feed entry summary
}
```

### Functions
- `fetchSec13FFeed(): Promise<SecFilingEntry[]>` — Fetches the SEC EDGAR Atom feed for 13F filings, parses entries, and extracts structured filing data
- `filterFilings(entries: SecFilingEntry[], opts: FilingsFilter): SecFilingEntry[]` — Client-side filter/sort
- `sortFilings(entries: SecFilingEntry[], sortBy: FilingsSort): SecFilingEntry[]` — Sort by newest, oldest, filer name

The feed parser should handle the SEC EDGAR Atom format, which uses `<entry>` elements with `<title>` containing filing type + company name, `<updated>` or `<published>` for date, `<link>` for URL, and `<id>` for accession number. Some entries include `<summary>` with filer CIK info.

### Fallback
If the RSS feed fails or returns empty, fall back to the existing `fetchInstitutionalHoldings(cik)` API for searching by CIK.

## 3. Merge Notable Tab → Institutions Tab in PortfolioPanel

**File:** `src/components/PortfolioPanel.ts`

### Remove "notable" from Tab type
```ts
type Tab = 'portfolio' | 'congress' | 'institutions' | 'visualizer';
```
Remove `notable` from `TAB_LABELS` and the switch case.

### Redesign Institutions Tab

The new Institutions tab will have **three sections** stacked vertically:

#### Section A: Live Filing Stream (top, default view)
- Shows the most recent 13F filings from the SEC EDGAR RSS feed
- Each filing row shows: filing type badge, filer name, CIK, date, link to EDGAR
- Sorted by "Newest" by default
- The RSS feed auto-refreshes; new filings appear live at the top

#### Section B: Quick Access — Notable Investors (inline)
- The 16 `NOTABLE_INVESTORS` cards now appear as a horizontal scrollable row or compact card list within the Institutions tab
- Each card is clickable: sets `institutionCik` and scrolls down to Section C
- This replaces the separate "Notable" tab — the content lives inline now

#### Section C: Institution Detail (bottom, conditional)
- When a filer is selected (from Quick Access or from clicking a filing row), shows the existing holdings breakdown
- Uses the same `fetchInstitutionalHoldings(cik)` API call
- Pre-selected when navigating from a notable card or clicking a filing entry

### UI Controls

Add a **toolbar** above the filing stream with:
- **Search input** — Filters filings by filer name, CIK, or filing type
- **Sort dropdown** — Options: "Newest first", "Oldest first", "Filer A-Z"
- **Filter dropdowns** — Filing type (13F-HR, 13F-NT, 13F-HR/A, all), Date range (Last 7 days, Last 30 days, Last quarter, All)
- **View toggle** — "Filings" (list) vs "Institutions" (card grid) view modes
