# Plan: Add Portfolio Visualizer Tab

## Overview
Add a **5th "Visualizer" tab** to the existing `PortfolioPanel` that provides **Backtest/Performance Chart** and **Asset Correlations** tools using the user's portfolio positions as input. Data will come from a new protobuf RPC (`ListHistoricalPrices`) added to the existing `MarketService`.

## Architecture

### New Tab: `visualizer`
The `PortfolioPanel` currently has 4 tabs (`portfolio`, `congress`, `institutions`, `notable`). We add `visualizer` as the 5th.

When the user switches to the Visualizer tab:
1. Read positions from `getUserPositions()` (localStorage, same as My Portfolio tab)
2. If no positions, show empty state prompting the user to add positions
3. If positions exist, show a **sub-tab bar**: `Performance` | `Correlations`
4. Each sub-tab fetches historical price data via the new `ListHistoricalPrices` RPC and renders its visualization

### Visualizer Sub-Tabs

#### Performance (Backtest)
- Fetches daily closing prices for each position's symbol (up to 2 years)
- Computes portfolio value over time: `sum(shares_i * price_i(t))` for each date
- Computes cost-basis line: `sum(shares_i * avgCost_i)` (constant horizontal line)
- Renders a **line chart** (D3 or lightweight-charts) showing:
  - Green/blue area: Portfolio value over time
  - Dashed line: Total cost basis
  - Hover tooltip: date + value + P&L %
- Below chart: summary cards (Total Return, CAGR, Max Drawdown, Sharpe)

#### Correlations
- Fetches daily returns for each position symbol (up to 1 year)
- Computes Pearson correlation matrix between all pairs
- Renders a **heatmap grid** (N×N where N = number of positions):
  - Color scale from red (−1) through white (0) to blue/green (+1)
  - Diagonal cells show "1.00" (self-correlation)
  - Hover shows exact correlation value + pair names
- Below heatmap: summary (Average Correlation, Most Correlated Pair, Least Correlated Pair)

```protobuf
}
```

## Key Design Decisions

- **D3 for charts** — Already in the dependency tree (used by globe.gl/deck.gl), no new dependency needed
- **Client-side correlation math** — Pearson correlation is trivial to compute client-side, no need for server-side computation
- **Up to 20 symbols per request** — Matches reasonable portfolio sizes; pagination not needed for MVP
- **Cache on server** — 15 min cache for price history, matching existing market data patterns
- **Sub-tabs for Visualizer** — Avoids one giant tab; Performance and Correlations are distinct workflows
- **Empty state when no positions** — Directs users to add positions in the My Portfolio tab first

## Module Boundaries

- `portfolio.ts` owns all computation (performance metrics, correlation matrix)
- `PortfolioPanel.ts` owns rendering and UI state (tab switching, loading states)
- Service handler owns data fetching from Yahoo Finance
- Proto definitions define the wire contract

This plan does NOT add a separate panel — it enhances the existing Portfolio Tracker with a clean 5th tab.
